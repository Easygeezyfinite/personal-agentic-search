# Personal Agentic Search

Search over my own notes, docs and email that runs entirely on my laptop. The
idea: keyword search is fine when I remember the exact word, but most of the time
I remember *roughly* what something said ("when does the flight to Vancouver
leave?"), so I want semantic retrieval plus a small agent that can look things up
in a few steps and answer with citations.

**Status:** just started. Project layout only.
